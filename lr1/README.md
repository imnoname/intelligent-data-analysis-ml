# Лабораторная работа №1 — вариант 6

Предмет: «Интеллектуальный анализ данных на основе методов машинного обучения».

## Тема работы

Построение моделей регрессии для прогнозирования показателя двигательных нарушений `motor_UPDRS` по данным голосовых измерений пациентов с болезнью Паркинсона.

Используемый датасет — Parkinsons Telemonitoring. Вариант 6 предполагает применение GRU и Min-Max нормализации.

## Содержимое ноутбука

Ноутбук `lr1_variant6_parkinsons_regression.ipynb` выполнен от начала до конца и содержит:

1. загрузку и первичный осмотр данных;
2. разведочный анализ с таблицами и графиками распределений, корреляций, выбросов и зависимостей признаков от целевой переменной;
3. проверку пропусков, дубликатов и типов данных;
4. обработку пропусков медианными значениями;
5. выявление и удаление почти нулевых признаков;
6. исключение `subject#` как идентификатора пациента и `total_UPDRS` как признака, создающего утечку целевой информации;
7. создание дополнительных признаков на основе показателей джиттера, шиммера, шума и взаимодействия возраста со временем;
8. отбор признаков с помощью F-теста;
9. масштабирование признаков методом Min-Max;
10. разделение данных на обучающую, валидационную и тестовую выборки;
11. обучение и сравнение Dense- и GRU-моделей;
12. использование Early Stopping, ReduceLROnPlateau и L2-регуляризации;
13. настройку GRU с помощью Grid Search;
14. дополнительное преобразование повторных измерений пациентов во временные последовательности и обучение GRU на окнах длиной 10;
15. оценку моделей по MSE, RMSE и коэффициенту детерминации `R²`.

## Основные результаты

В табличной постановке лучшей оказалась Dense-модель на исходных признаках после преобразования:

- тестовый RMSE: примерно `6.30`;
- тестовый `R²`: примерно `0.42`.

После настройки GRU методом Grid Search:

- лучшие параметры: `units=64`, `dropout=0.0`, `learning_rate=0.001`;
- тестовый RMSE: примерно `7.58`;
- тестовый `R²`: примерно `0.15`.

В дополнительном эксперименте с временными последовательностями длиной 10 получены RMSE около `6.83` и отрицательный `R²`. Это означает, что при строгом разделении по пациентам GRU обобщила данные на новых пациентов хуже простого прогноза средним значением. Такой эксперимент показывает разницу между обычной табличной постановкой и прогнозированием следующего наблюдения во временном ряду.

## Как запустить

Откройте ноутбук в Jupyter Notebook или VS Code, выберите ядро Python с установленным TensorFlow и выполните ячейки сверху вниз.

## Целевая переменная и признаки

Целевая переменная — `motor_UPDRS`. На вход моделей поступают демографические, временные и голосовые характеристики: возраст, пол, время измерения, показатели джиттера и шиммера, NHR, HNR, RPDE, DFA и PPE. Идентификатор пациента и `total_UPDRS` в качестве входов не используются.

### Подробное описание признаков

Целевая переменная `motor_UPDRS` — оценка двигательных нарушений пациента. Чем выше её значение, тем сильнее выражены двигательные симптомы.

| Признак | Описание |
|---|---|
| `age` | Возраст пациента. Может быть связан с естественными изменениями голоса и тяжестью симптомов. |
| `sex` | Пол пациента, закодированный числом 0 или 1. |
| `test_time` | Время от начала наблюдения пациента. Позволяет учитывать изменение состояния во время обследований. |
| `Jitter(%)` | Относительная нестабильность частоты основного тона, то есть степень «дрожания» высоты голоса. |
| `Jitter(Abs)` | Абсолютное изменение периода основного тона во времени. |
| `Jitter:RAP` | Нестабильность частоты, рассчитанная по трём соседним периодам голоса. |
| `Jitter:PPQ5` | Нестабильность частоты, рассчитанная по пяти соседним периодам. |
| `Jitter:DDP` | Разность изменений частоты между соседними периодами. |
| `Shimmer` | Относительная нестабильность амплитуды голоса, то есть изменение громкости отдельных периодов. |
| `Shimmer(dB)` | Нестабильность амплитуды, выраженная в децибелах. |
| `Shimmer:APQ3` | Нестабильность амплитуды по трём соседним периодам. |
| `Shimmer:APQ5` | Нестабильность амплитуды по пяти соседним периодам. |
| `Shimmer:APQ11` | Нестабильность амплитуды по одиннадцати соседним периодам. |
| `Shimmer:DDA` | Разность изменений амплитуды между соседними периодами. |
| `NHR` | Отношение шума к гармонической составляющей. Большие значения указывают на более шумный голос. |
| `HNR` | Отношение гармонической составляющей к шуму. Большие значения соответствуют более гармоничному голосу. |
| `RPDE` | Показатель нерегулярности движения голосовых связок и сложности голосового сигнала. |
| `DFA` | Показатель долгосрочных зависимостей и самоподобия голосового сигнала. |
| `PPE` | Энтропия периода высоты тона, характеризующая непредсказуемость и нестабильность голоса. |

### Созданные признаки

В процессе feature engineering были добавлены следующие признаки:

| Признак | Описание |
|---|---|
| `jitter_mean` | Среднее значение нескольких показателей нестабильности частоты. |
| `jitter_max` | Максимальное значение показателей джиттера. |
| `shimmer_mean` | Среднее значение показателей нестабильности амплитуды. |
| `shimmer_max` | Максимальная нестабильность амплитуды. |
| `noise_to_harmonics_ratio` | Дополнительная характеристика отношения шума к гармоникам на основе `NHR` и `HNR`. |
| `age_x_test_time` | Произведение возраста на время наблюдения, учитывающее их совместное влияние. |

Голосовые признаки используются потому, что болезнь Паркинсона влияет на управление голосовыми связками. Это может проявляться в дрожании частоты, нестабильности громкости, повышении шумовой составляющей и нерегулярности голоса.

### Исключённые признаки

- `subject#` — идентификатор пациента, не содержащий полезной измерительной информации;
- `total_UPDRS` — общий показатель UPDRS, связанный с `motor_UPDRS`. Его использование могло бы привести к утечке целевой информации;
- `motor_UPDRS` — целевая переменная, поэтому она не передаётся на вход модели.
